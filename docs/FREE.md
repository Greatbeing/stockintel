# 为什么能做到完全免费

## 每一项免费在哪

| 环节 | 免费来源 | 限制 |
|---|---|---|
| 行情 | AkShare 开源库 + 东财公开接口 | 免费接口有频率限制；不保证实时性 |
| LLM | NVIDIA Nemotron 3 Ultra 550B（NVIDIA NIM 经 Magpie；备选 LongCat `magpie/longcat/LongCat-2.5`，用 `--model` 指定） | 免费额度有限，耗尽即停；约 20 秒/次 |
| 运行 | 本地电脑 / 免费云机（如 InstaBox 免费套餐） | 免费云机按量休眠，不适合 24 小时服务 |
| 依赖 | Python 标准库 | 无 |

## 额度耗尽时会发生什么

- `llm/review_lean.py`：模型调用失败即报错退出，不写报告，不静默换模型
- `report/build_report.py`：纯组装，不调模型，不受影响
- 恢复办法：等额度恢复，或用 `--model` 指定另一个免费模型

## 什么情况下会花钱

- 本系统本身不产生任何费用。如果你把数据换成付费行情、把模型换成付费 API，那是你自己的选择，与本系统无关。
- 免费云机超出免费额度（如长期运行不休眠）可能产生费用；请按云厂商的免费规则使用。

## 免费不是无限制

免费额度、免费接口都有用量上限。本系统的设计原则是：额度到了就停下来报错，而不是偷偷降级或扣费。
